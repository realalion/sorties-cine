# Sorties Ciné France

Application web (PWA) des prochaines sorties cinéma en France, avec la date officielle.

**En ligne :** https://realalion.github.io/sorties-cine/

Sur iPhone (Safari) : Partager → **Sur l’écran d’accueil**.

Les données viennent de l’agenda AlloCiné et sont rafraîchies chaque jour via GitHub Actions (`scripts/fetch_allocine.py`).
